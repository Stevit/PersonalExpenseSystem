# PersonalExpenseSystem - Sistema di Gestione delle Spese Personali e del Budget

## Requisiti per l'esecuzione
- Interprete: Python 3.10 o versioni successive
- Librerie standard utilizzate:
  - `sqlite3`
  - `os`

Non sono richieste librerie esterne da installare.

## Istruzioni dettagliate per eseguire il programma
Il programma è scritto in Python, pertanto non necessita di alcuna fase di compilazione.

Per avviare l'applicazione, posizionarsi nella cartella principale del progetto ed eseguire il seguente comando da terminale:

```bash
python src/main.py
```
